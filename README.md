# 🏀 App Busca de Times NBA

Aplicativo desenvolvido em React Native com Expo para busca de times da NBA.

## Funcionalidades
- 🔍 Busca de times da NBA por nome
- 📋 Detalhes do time ao clicar no card
- 🏀 Foto e estatísticas do jogador principal
- 🌐 Integração com a API Ball Don't Lie

## Tecnologias
- React Native
- Expo SDK 56
- TypeScript
- API: balldontlie.io

## Como rodar
npm install
npx expo start --web
